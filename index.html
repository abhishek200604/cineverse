CLOUD ARCHITECTURE

Engineered with AWS Serverless

A high-concurrency, production-grade cloud backend supporting real-time seat locks and atomic transactions.

API GATEWAY

REST API Router

AWS API Gateway regional endpoint in ap-south-1 routes client requests to serverless Lambda microservices.

  • Rate limiting & validation
  • Low latency Mumbai edge
  • Direct proxy to handlers
AWS LAMBDA

Atomic Reservation Engine

Stateless Python/Node handlers execute seat check and reservation logic within milliseconds.

  • Single seat booking via /book-ticket
  • Batch reservation via /book-group
  • Idempotent status updates
AMAZON DYNAMODB

Sub-Millisecond Seat State

NoSQL data store using conditional expression writes to strictly eliminate race conditions & double bookings.

  • Partition key: Show ID & Seat ID
  • Optimistic concurrency locking
  • HTTP 409 Conflict protection
AMAZON SNS & S3

Notifications & Hosting

Amazon Simple Notification Service delivers email confirmations while Amazon S3 hosts this static SPA with zero servers to manage.

  • Instant email receipts
  • Global static website hosting
  • 99.99% infrastructure uptime

💡 CORS Troubleshooting Guide

If your browser shows Failed to fetch due to CORS restrictions, this occurs when API Gateway has not yet returned Access-Control-Allow-Origin: *.

How to resolve in AWS:
  1. Open AWS API Gateway Console → Select your API (jtajs6rkjk).
  2. Under Resources, select your routes (/shows, /seats, etc.) → Click Enable CORS.
  3. In your Lambda function responses, ensure headers include: 
    headers: {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Headers": "Content-Type",
  "Access-Control-Allow-Methods": "OPTIONS,GET,POST,DELETE"
}
  4. Click Deploy API to the stage to apply changes live.
